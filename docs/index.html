Review the PR against the ticket, not just the code.

Agentic PR Review reads the ticket a pull request claims to implement, checks every requirement, flags what could break, and spots other open PRs touching the same files. It keeps one comment, updated on every push. A human makes the final call.

Setup

on:
  pull_request:
    types: [opened, synchronize, reopened, edited]

permissions:
  contents: read
  pull-requests: write
  issues: write

jobs:
  review:
    runs-on: ubuntu-latest
    steps:
      - uses: hitesh-bhayani/agentic-pr-review@v1
        with:
          anthropic-api-key: ${{ secrets.ANTHROPIC_API_KEY }}

Link tickets with Fixes #12 in the PR description, or put a Jira key like PROJ-42 in the title or branch name. Add JIRA_BASE_URL, JIRA_EMAIL and JIRA_API_TOKEN to read Jira tickets.
